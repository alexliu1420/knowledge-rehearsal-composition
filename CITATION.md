# Citation Information

Guidance on citing Alex Liu's "What You Rehearse Is What You Keep: Rehearsal Format Decides Whether
Known Facts Stay Composable."

**For citing the latest version**, use the concept DOI, which always resolves to the most recent
release: `10.5281/zenodo.[CONCEPT-DOI]`.

## Version 0.1.0 — initial public release

**Plain text**

Liu, A. (2026). *What You Rehearse Is What You Keep: Rehearsal Format Decides Whether Known Facts
Stay Composable* (Version 0.1.0). Zenodo. https://doi.org/10.5281/zenodo.[VERSION-DOI]

**BibTeX**

```bibtex
@misc{liu2026rehearsal,
  author    = {Liu, Alex},
  title     = {What You Rehearse Is What You Keep: Rehearsal Format Decides Whether Known
               Facts Stay Composable},
  year      = {2026},
  publisher = {Zenodo},
  version   = {0.1.0},
  doi       = {10.5281/zenodo.[VERSION-DOI]},
  url       = {https://doi.org/10.5281/zenodo.[VERSION-DOI]}
}
```

The DOI placeholders are filled in at deposit time; the `[CONCEPT-DOI]` and `[VERSION-DOI]`
markers are checked for by the release build.
